Reports if, match, and try statements that can be converted to expressions by lifting the return statement or an assignment out.

Every branch must end with a return, or with an assignment to the same variable. Branches ending with throw are left as they are.

Example:


  def describe(n: Int): String = {
    n match {
      case 0 => return "zero"
      case 1 => return "one"
      case _ => return "many"
    }
  }

After the quick-fix is applied:


  def describe(n: Int): String = {
    return n match {
      case 0 => "zero"
      case 1 => "one"
      case _ => "many"
    }
  }

If you would like this inspection to highlight more complex code with multi-statement branches, uncheck the option "Report only if each branch is a single statement".

The reverse conversion is available as the Unfold return or assignment into 'if', 'match' or 'try' branches intention.
