Converts a match expression, whose cases contain only literals, stable identifiers, type tests, alternatives and wildcards, to an equivalent if-else if-else chain. Guards are joined to the conditions with &&.

A scrutinee other than a literal or a path to a value (e.g. a method call) is first stored in a local val, so that it is still evaluated only once. If the match is not a statement of a block (e.g. it is the whole body of a method), the val and the if chain are wrapped in a new block.
