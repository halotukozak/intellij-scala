Reports reassignments of variables that can be simplified with an assignment operator:

  • x = x op e can be replaced with x op= e, for example seq = seq :+ 4 with seq :+= 4;
  • x = e op: x with a right-associative operator can be replaced with x op:= e, for example list = 0 :: list with list ::= 0;
  • map = map.updated(k, v) on an immutable map can be replaced with map += k -> v.

The inspection is reported only when the assignment operator desugars into the very same reassignment, that is, when the type of the variable has no op= method of its own (as, for example, mutable collections do).

Use the option below to exclude right-associative operators.

The quick-fix replaces the reassignment with an assignment operator.

Example:


  var counter = 0
  counter = counter + 2
  var list = List(1, 2, 3)
  list = 0 :: list

After the quick-fix is applied:


  var counter = 0
  counter += 2
  var list = List(1, 2, 3)
  list ::= 0
